# ivm-bench

Benchmarks Incremental View Maintenance capabilities on various Open Source engines with [the TPC-DI-based data model](https://www.tpc.org/tpcdi/) for **educational purposes**.

## Dev Setup

See [`contrib/README.md`](contrib/README.md).

## Quickstart

### Benchmark

Generate TPC-DI data as Delta Lake and run the dbt benchmark per engine serially:

```bash
export GIT_ROOT=$(git rev-parse --show-toplevel)
export SCALE_FACTOR=5

sudo rm -rf ${GIT_ROOT}/mount/raw/${SCALE_FACTOR}
bash src/.scripts/benchmark.sh
```

## Mount layout

| Path                                            | Description                                          |
| ----------------------------------------------- | ---------------------------------------------------- |
| `mount/raw/<SF>/digen/`                         | Raw TPC-DI flat files generated by DIGen/PDGF        |
| `mount/raw/<SF>/delta/`                         | Delta Lake tables (CDF enabled) converted from digen |
| `mount/results/<SF>/spark/`                     | Spark warehouse (Delta tables from dbt build)        |
| `mount/results/<SF>/duckdb/`                    | DuckDB database file from dbt build                  |
| `mount/results/<SF>/dbt-server/state.db`        | SQLite — dbt run history, per-node DAG timing        |
| `mount/results/<SF>/dbt-server/run-spark.json`  | Spark benchmark results (DAG, timing, compiled SQL)  |
| `mount/results/<SF>/dbt-server/run-duckdb.json` | DuckDB benchmark results (DAG, timing, compiled SQL) |

## Disclaimer

As this repo's implementation of the TPC-DI is an unpublished and unofficial TPC Benchmark, the following is required legalese per TPC Fair Use Policy:

> The `ivm-bench` TPC-DI is derived from the TPC-DI source data to test Incremental View Maintenance and as such is NOT comparable to officially published TPC-DI results.
